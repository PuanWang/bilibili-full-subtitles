# 哔哩哔哩完整字幕

一个在 B 站视频页显示完整字幕的浏览器用户脚本。打开「完整字幕」面板后，可以一次阅读当前分 P 的整条字幕轨，搜索关键词，点击时间戳跳回对应片段，或复制整份字幕做笔记。

脚本读取 B 站已经提供的投稿字幕或 AI 字幕，显示可用的语言和来源。视频没有可读取的字幕时，面板会给出提示。脚本不转录音频，也不生成字幕。

## 安装

1. 按浏览器选择一个用户脚本管理器。
   - **Chrome** 可使用 Tampermonkey。如果扩展提示需要允许用户脚本，按其说明开启权限。[Tampermonkey 权限说明](https://www.tampermonkey.net/faq.php?q=Q209)
   - **Safari** 可使用 Userscripts。启用扩展并允许它访问 `www.bilibili.com`。[Userscripts 安装与使用说明](https://github.com/quoid/userscripts#usage)
2. 用该浏览器打开 [脚本原始文件](https://raw.githubusercontent.com/PuanWang/bilibili-full-subtitles/main/bilibili-full-subtitles.user.js)。在 Tampermonkey 中确认安装。使用 Safari Userscripts 时，打开扩展菜单查看安装提示，也可以将文件保存到 Userscripts 的脚本目录。若浏览器只显示源码，可在脚本管理器中导入该 `.user.js` 文件，或新建脚本并粘贴完整源码。
3. 打开或刷新 `www.bilibili.com` 上的普通视频页，点击默认位于右下角的 **完整字幕**。更新时可通过同一链接重新安装，或用最新版源码覆盖已有脚本。

## 使用

| 想做什么 | 怎么操作 |
| --- | --- |
| 阅读当前分 P 的字幕 | 点 **完整字幕** 打开面板，在下拉框中选择字幕轨。切换分 P 时，已打开的面板会重新读取当前分 P 的字幕。 |
| 找到一句话或回看原片 | 在 **搜索字幕** 中输入关键词。点击结果左侧的时间戳，播放器会跳到对应位置。 |
| 复制整份字幕 | 点 **复制全文**，复制当前字幕轨的全部正文。即使正在搜索，复制的仍是全文。 |
| 移动按钮或调整面板大小 | 按住 **完整字幕** 按钮拖动。打开面板后，拖动角落的浅蓝色标记调整宽高。键盘聚焦按钮或角标后，也可用方向键调整。 |
| 在同一面板里看更多行 | 点 **A−** 缩小正文和时间戳，点 **A+** 放大，可调范围为 12–32 px。点 **精简** 收起标题、工具栏和分 P／条数统计，点 **显示工具** 恢复。 |

按钮位置、面板尺寸、字号和精简状态保存在当前浏览器中，刷新页面后会恢复。

## 常见问题

- **没有「完整字幕」按钮**。确认脚本已启用、扩展有权在 B 站运行，并刷新 `www.bilibili.com/video/…` 这类普通视频页。脚本目前面向 BV／av 视频页。
- **没有字幕或提示需要登录**。字幕取决于当前分 P 和账号能访问的字幕轨。如果提示需要登录，先登录 B 站，再点 **重新加载**。
- **复制失败**。如果浏览器拒绝剪贴板权限，可以直接选中面板里的字幕文字手动复制。
